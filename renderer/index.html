这个客户端是什么

            

              它把上游 rea-video（Apache-2.0）的命令行流水线包成桌面工具：探测本机 Python / FFmpeg，调度拆解任务，实时显示进度，最后打开
              report.html 报告。所有拆解计算都在本机完成，不经过任何服务器。
            

            

              客户端本身不包含模型权重。你配置的多模态模型只接收镜头片段与关键帧；密钥用系统凭据加密后存在本机。
